# BharatMedia V3 — 3-Minute Demo Script
## WeMakeDevs × AWS "Ship It" Hackathon

## The Hook (0:00–0:20)

> "85 million Indian businesses. Most of them can't afford a marketing agency.
> BharatMedia gives them an autonomous AI growth agent that understands their
> local audience, creates culturally relevant campaigns, runs experiments,
> and learns from every campaign it runs."

**What makes this different from any other AI tool:**
- It's not a form that calls an LLM
- It's an autonomous agent loop: Research → Create → Validate → Learn
- Every decision is backed by evidence and stored for next time

## Demo Scenario — "Bengaluru Restaurant Weekend Campaign" (0:20–2:30)

### Input (0:20)
```
Business:  Namma Bengaluru Kitchen
Goal:      Increase weekend orders
Region:    Indiranagar, Bengaluru
Language:  Kannada + English
```

### Show the real-time pipeline (0:30)
Watch the 5 stages complete live — each stage is a real Bedrock call:

| Stage | Agent | Real AWS Call |
|---|---|---|
| Stage 1 | Research Agent | Nova Pro via Bedrock InvokeModel |
| Stage 2 | Creative Swarm | Nova Lite + Titan Image → S3 |
| Stage 3 | Quality Guard | Nova Pro content safety check |
| Stage 4 | Distribution | Nova Lite posting time analysis |
| Stage 5 | Finalise | DynamoDB write + Experiment create |

### Pause on Stage 1 output (0:55)
> "Notice the evidence array — the AI doesn't just say 'use Kannada.' It shows WHY:
> based on the regional market signals and past campaign lessons stored in DynamoDB."

### Show the generated image (1:15)
> "The image was generated by Amazon Titan Image Generator — not DALL-E, not Stable Diffusion.
> Uploaded directly to S3. That's the real URL you see there."

Open the S3 console — show the image key `campaigns/2026/09/<uuid>.png`.

### Open BharatBrain (1:30)
> "Before this campaign ran, I uploaded my brand guidelines and product menu.
> The AI reads from S3 and uses DynamoDB metadata to understand MY business."

Show the document list with S3 badge on each item.

### Open Agent Trace (1:45)
> "Every single agent decision is logged to DynamoDB. I can see exactly what
> input went in, what came out, and how long it took."

Show the trace timeline: `research_market → creative_swarm → quality_guard → distribution_agent → experiment_engine`

### Open Experiment Lab (2:00)
> "The pipeline automatically created 3 content variants —
> Kannada, English, and bilingual. These are stored as a live experiment in DynamoDB.
> As I collect performance data, the next campaign will automatically use the winning strategy."

### Open Learning Memory (2:15)
> "And it learned from this campaign. That lesson is stored in DynamoDB and
> will be retrieved before the NEXT campaign for this business."

## Known Talking Points for Judges

**"Why Strands Agents and not just chained prompts?"**
> The research agent uses a registered Tool definition. The tool handler is the real
> Nova Pro call. This means when `@strands-agents/sdk` ships publicly, this is a
> one-line swap — the call sites are identical.

**"What's real vs simulated?"**
> - Real: DynamoDB, S3, Bedrock Nova Pro/Lite, Titan Image
> - Simulated (labelled): Market Pulse signals (no social API licence)
> - Simulated (labelled): Campaign Simulator reach estimates (model-based, not real analytics)

**"What would you do with more time?"**
> - Connect real Bedrock Guardrails API with a provisioned GuardrailId
> - Integrate Bedrock Knowledge Bases for BharatBrain (hybrid search)
> - Step Functions state machine for resilient orchestration
> - Real social API for Market Pulse
